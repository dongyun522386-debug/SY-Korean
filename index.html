연음 (Liaison / 连音)
받침(종성)으로 끝나는 단어 뒤에 모음이 오면 받침이 다음 음절 초성으로 이어져 발음됩니다.
当以收音结尾的词后面接元音时，收音会转移到下一个音节。
예: 먹어요 → [머거요], 읽어요 → [일거요]
경음화 (Fortis / 紧音化)
받침 ㄱ,ㄷ,ㅂ 뒤에 예사소리가 오면 된소리로 변합니다.
收音ㄱ,ㄷ,ㅂ后接平音时变为紧音。
예: 학교 → [학꾜], 식당 → [식땅]
비음화 (Nasalization / 鼻音化)
받침 ㄱ,ㄷ,ㅂ 뒤에 ㄴ,ㅁ이 오면 ㅇ,ㄴ,ㅁ으로 변합니다.
收音ㄱ,ㄷ,ㅂ后接鼻音ㄴ,ㅁ时发生鼻音化。
예: 국민 → [궁민], 입문 → [임문]
격음화 (Aspiration / 激音化)
ㅎ과 예사소리가 만나면 거센소리로 변합니다.
ㅎ与平音相遇时变为激音。
예: 좋다 → [조타], 많다 → [만타]
ㅢ 발음 (Pronunciation of ㅢ)
단어 첫음절의 ㅢ는 [ㅢ], 이후는 [ㅣ], 조사로 쓰일 때는 [ㅔ]로 발음합니다.
词首ㅢ发[ㅢ]，其他位置发[ㅣ]，用作助词时发[ㅔ]。
예: 의사 → [의사], 회의 → [회이], 나의 → [나에]
